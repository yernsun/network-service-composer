# Historical product preview screenshots

These screenshots document the NSC preview surface before the product rename.
They retain the original brand as historical capture evidence; the current product
name is Network Service Composer for Nginx. The desktop captures
used browser artifacts generated on 2026-09-15; mobile captures use a
390 × 844 viewport where noted. Demo-operation images show local simulated state
and do not represent live infrastructure.

Installation captures numbered 01–13 contained real project/domain identifiers.
They are retained only in restricted local evidence and excluded from community
source snapshots. Remaining demo captures are historical presentation examples,
not acceptance evidence for the current release candidate.
