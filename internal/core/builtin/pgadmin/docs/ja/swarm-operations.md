# pgAdmin: Compose と Swarm のデプロイ

pgAdmin はポート 80 で管理者メールとパスワードを使います。DATABASE_NETWORK に既存 PostgreSQL ネットワークを指定し、ログイン後に DB サーバーを手動登録します。PostgreSQL 自体は作成しません。データ: /var/lib/pgadmin。

このバージョンは Docker Compose と Swarm Service をサポートします。Swarm では単一レプリカを選択したデータノードに固定し、ローカル名前付きボリュームと停止後に起動する更新を使用します。データノードがオフラインでも他のノードには移動しません。

Ready/Active のデータノードを選択します。永続サービスは単一レプリカでこのノードに固定され、オフライン時は利用できません。

停止後も名前付きボリュームを保持します。再起動には、元のボリュームが同じノードに残っていることを示す新しい証拠が必要です。欠落や置換があれば起動を拒否します。ノード変更や永続レプリカの追加には別途データ移行が必要です。

データベースと永続ファイルを別々にバックアップします。設定のロールバックはデータを復元しません。初期認証情報は空のボリュームにのみ適用されます。WordPress には MySQL が含まれ、初回アクセスでサイト管理者を設定します。

停止結果が不明な場合、停止を再実行してタスクの終了と元のボリュームの保持を確認するまで起動できません。初回インストールの結果が不明な場合、空の代替ボリュームで再試行できません。元のストレージを識別できない場合は、検証済みのバックアップから復元してください。
