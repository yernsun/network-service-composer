# 安裝與維護

phpMyAdmin 透過 DATABASE_NETWORK 連線 PMA_HOST 和 PMA_PORT。在 80 連接埠登入頁填寫既有 MySQL 憑證。不啟用自動登入或任意伺服器選擇。工作階段：/sessions。

選擇固定市場版本，閱讀參數並填寫自己的機密。密碼沒有可用預設值，至少使用 16 位元組。不要將真實機密提交到市場。

執行預檢，檢查 Compose 定義、資料卷和網路相依項目，再確認安裝。查看工作及各容器健康結果；執行中本身不等於健康。

資料庫只開放內部連接埠。僅為 Web 應用建立含 TLS 的 HTTP Route，並先確認 Gateway 可存取服務。

儲存與連線

更新前使用適合應用的工具備份資料卷和資料庫，並驗證還原。還原映像或設定不會還原業務資料。

停止應用會保留具名資料卷。刪除應用不得隱含刪除持久資料。保留還原材料並確認後續更新責任。

這些範本不發布主機連接埠。外部資料庫網路必須事先存在，且可從應用存取。

同步市場新增不可變版本，不更新已安裝的工作負載。下架版本保留歷史，但不能再次安裝。
