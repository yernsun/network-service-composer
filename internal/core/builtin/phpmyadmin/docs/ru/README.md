# phpMyAdmin

phpMyAdmin подключается к PMA_HOST и PMA_PORT через DATABASE_NETWORK. На порту 80 войдите с существующими данными MySQL. Автовход и выбор произвольного сервера отключены. Сеансы: /sessions.

Выберите среду Docker Compose с включённым управлением. Установка этих шаблонов с состоянием в Swarm заблокирована.

## Параметры

- `PMA_HOST`
- `PMA_PORT` = `3306`
- `DATABASE_NETWORK`

Выберите фиксированную версию, изучите параметры и введите свои секреты. У паролей нет пригодных значений по умолчанию; используйте не менее 16 байт. Не публикуйте настоящие секреты в каталоге.
