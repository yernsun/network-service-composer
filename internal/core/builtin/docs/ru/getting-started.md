# Начало работы

Шаблоны не публикуют порты узла. Внешние сети баз данных должны существовать заранее и быть доступны приложению.

Выберите среду Docker Compose с включённым управлением. Установка этих шаблонов с состоянием в Swarm заблокирована.

Выберите фиксированную версию, изучите параметры и введите свои секреты. У паролей нет пригодных значений по умолчанию; используйте не менее 16 байт. Не публикуйте настоящие секреты в каталоге.

Выполните предварительную проверку, изучите Compose, тома и сетевые зависимости, затем подтвердите установку. Проверьте операцию и состояние каждого контейнера: работающий контейнер не обязательно исправен.

Базы данных открывают только внутренние порты. Создавайте HTTP Route с TLS только для веб-приложений после проверки доступа от Gateway к сервису.

Перед обновлением создайте резервные копии томов и баз подходящими средствами и проверьте восстановление. Восстановление образа или конфигурации не восстанавливает бизнес-данные.

Остановка сохраняет именованные тома. Удаление приложения не должно неявно удалять постоянные данные. Сохраните материалы восстановления и назначьте ответственного за обновления.

Синхронизация добавляет неизменяемые версии и не обновляет установленные нагрузки. Снятая версия остаётся в истории, но недоступна для новой установки.
