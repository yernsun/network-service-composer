# インストールと保守

PostgreSQL 18 はポート 5432 を使います。旧パス /var/lib/postgresql/data ではなく親ディレクトリ /var/lib/postgresql をマウントします。

固定された市場バージョンを選び、パラメーターを確認して独自の秘密情報を入力します。パスワードに使用可能な既定値はなく、16 バイト以上必要です。実際の秘密情報を市場に登録しないでください。

事前検証を実行し、Compose 定義、ボリューム、ネットワーク依存関係を確認してからインストールを確定します。処理結果と各コンテナーのヘルスチェックを確認してください。実行中であるだけでは正常とは限りません。

データベースは内部ポートのみを公開します。Web アプリケーションにのみ TLS 付き HTTP Route を作成し、事前に Gateway からサービスへ接続できることを確認します。

ストレージと接続

更新前にアプリケーションに適したツールでボリュームとデータベースをバックアップし、復元を検証します。イメージや設定の復元では業務データは復元されません。

アプリケーションを停止しても名前付きボリュームは保持されます。削除時に永続データを暗黙に消してはいけません。復旧資料を保持し、今後の更新担当者を決めてください。

これらのテンプレートはホストのポートを公開しません。外部データベースのネットワークは既存で、アプリケーションから接続可能である必要があります。

市場の同期は不変バージョンを追加し、インストール済みワークロードを更新しません。公開終了したバージョンの履歴は残りますが、新規インストールはできません。
