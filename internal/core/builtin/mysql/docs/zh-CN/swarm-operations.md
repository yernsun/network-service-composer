# MySQL: Compose 与 Swarm 部署

MySQL 使用独立 root 和应用密码。连接端口 3306；数据：/var/lib/mysql。

此版本支持 Docker Compose 和 Swarm Service。Swarm 使用单副本、固定数据节点、本地命名卷和先停止再启动的更新方式。数据节点离线时不会调度到其他节点。

选择 Ready/Active 数据节点。持久化服务使用单副本并固定在此节点；节点离线时服务暂停。

停止保留命名卷。再次启动前必须取得新鲜证据，确认原卷仍在同一节点；卷缺失或被替换时阻止启动。更换节点或增加持久化副本需要单独迁移数据。

分别备份数据库内容和持久化文件。配置回滚不会恢复数据。初始化凭据仅适用于空卷。WordPress 自带 MySQL；首次访问时完成网站管理员设置。

停止结果未知时，启动保持阻断，直到再次停止并确认任务退出、原卷保留。首次安装结果未知时，不能通过空替代卷重新部署；若无法确认原存储，应从已验证的备份恢复。
