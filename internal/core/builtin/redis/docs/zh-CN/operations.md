# 安装与维护

Redis 缓存启用 AOF 持久化；连接 6379 端口需要认证。数据：/data。

选择固定市场版本，阅读参数并填写自己的秘密。密码没有可用默认值，至少使用 16 字节。不要把真实秘密提交到市场。

执行预检，检查 Compose 定义、数据卷和网络依赖，然后确认安装。查看任务及各容器健康结果；运行中本身不等于健康。

数据库只开放内部端口。仅为 Web 应用创建带 TLS 的 HTTP Route，并先确认 Gateway 可以访问服务。

存储与连接

更新前使用适合应用的工具备份数据卷和数据库，并验证恢复。恢复镜像或配置不恢复业务数据。

停止应用保留命名数据卷。删除应用不得隐式删除持久数据。保留恢复材料并明确后续更新责任。

这些模板不发布宿主机端口。外部数据库网络必须预先存在，并能从应用访问。

同步市场新增不可变版本，不更新已安装工作负载。下架版本保留历史，但不能再次安装。
